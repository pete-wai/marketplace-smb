# What the first snapshot suggests

Snapshot: October 30, 2026. These are evidence shares among resolved commercial provider identities, not independently adjudicated eligibility rates. Current source and reasoning are available in [providers.csv](../../static/downloads/providers.csv).

## Current participation

| Pathway | Certified: documented small / total | Initial implementation: documented small / total |
| --- | ---: | ---: |
| Rev5 / traditional | 89 / 430 (20.7%) | 7 / 14 (50.0%) |
| 20x Pilot | 10 / 25 (40.0%) | 0 / 0 (not applicable) |
| 20x non-pilot | 0 / 8 (0.0% documented; all eight unresolved) | 38 / 86 (44.2%) |

The pilot has a higher documented small-business share than the traditional certified population, and the non-pilot initial-implementation population contains many documented small-business representations. This is consistent with small firms participating in newer routes. It does not establish increased access relative to a comparable applicant population.

All eight currently certified non-pilot 20x provider size classifications remain unknown under this study’s conservative rule. Some are private companies with substantial public ARR disclosures; ARR is not the five-year average of completed-year receipts. Others lack usable public financial information. **The table does not mean none is small.** Provider-level reasoning retains these differences.

## The recent two-year comparison

The latest window is October 31, 2024–October 30, 2026; the preceding window is October 31, 2022–October 30, 2024.

- Resolved providers with a first product certification in the window increased from 83 to 231; first-observed entrants increased from 71 to 205.
- Using dated historical size evidence, likely-small providers increased from 2/83 (2.4%) to 9/231 (3.9%). Historical size is unknown for 75.9% and 79.2%, respectively. These percentages are too incomplete to support a reliable change-in-prevalence estimate.
- Using **current** size evidence instead, documented-small membership is 13/83 (15.7%) in the earlier cohort and 56/231 (24.2%) in the later cohort. This describes those companies today. It must not be reported as their size at certification.

Unknown denominators, changes in listing coverage, pilot selection, impact/class mix, ownership changes, and unobserved prior certifications limit interpretation. Higher volume is not by itself evidence of reduced burden or a causal policy effect.

## Most valuable next additions

Date-specific SAM representations and contracting-officer size determinations matched by UEI and procurement NAICS; historical ownership; complete applicant and unsuccessful-applicant populations; time-to-certification and cost evidence with comparable starting points. New factors should be added as separate observations, with dates and sources, so they can be tested without erasing the current evidence trail.
